# Group Seminar Slides

This is my Ph. D. mid-term defense on 20th November, 2025 based on my article _Universal spreading dynamics in quasiperiodic non-Hermitian systems_, [Phys. Rev. B **111**, L180203 (2025)](https://link.aps.org/doi/10.1103/PhysRevB.111.L180203)

## How to start the slide show locally

- Clone this repository to your machine:
```bash
git clone https://github.com/xing-phys/Univ-Sprd-Quasiper-NH.git
```
- Navigate to the project repository:
```bash
cd Univ-Sprd-Quasiper-NH
```
- Install dependecies: `pnpm install`
- Start Slidev: `pnpm dev`
- Visit <http://localhost:3030>
